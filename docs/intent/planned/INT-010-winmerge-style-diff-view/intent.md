# Intent: 파일 내용 비교 화면을 차이 탐색이 쉬운 좌우 비교 뷰어로 개선

## 문제 (Problem)
- INT-009의 내용 비교 모달은 좁은 모달(폭 최대 760px, 행 영역 높이 최대 520px) 안에 한 표로 좌우를 나란히 놓는다. 긴 파일에서 다른 부분이 어디에 몇 군데 있는지 한눈에 보이지 않고, 스크롤로 직접 찾아야 한다.
- 다음·이전 차이로 이동하는 수단(툴바·단축키)이 없다. 한 줄이 길거나 비슷한 두 줄은 좌우를 눈으로 맞춰 봐야 해서 어디가 다른지 알기 어렵다.
- 영향 사용자: 동기화 전에 변경 파일 내용을 검토하는 앱 사용자(작성자 본인).

## 제안 결과 (Proposed outcome)
- 비교 화면이 사용자가 익숙한 좌우 비교 뷰어처럼 동작한다: 왼쪽 원본·오른쪽 대상 패널, 각 패널 위에 경로 표시, 다른 줄은 빨간 계열 배경으로 강조, 빈 쪽(한쪽에만 있는 줄)은 빗금 등 빈 줄 표시.
- 맨 왼쪽에 파일 전체를 축소한 위치 막대가 있어 차이가 있는 위치가 표시되고, 누르면 그 위치로 이동한다.
- 줄을 선택하면 화면 아래 영역에 그 줄의 원본(위)·대상(아래)을 위아래로 겹쳐 보여 줘서 같은 줄의 차이를 바로 비교할 수 있다.
- 툴바의 ↓ 화살표는 다음 차이로, ↑ 화살표는 이전 차이로 이동하고 해당 차이를 선택한다. 남은 차이 개수(예: "차이 7곳 중 3")가 보인다.
- 여전히 읽기 전용이다. 편집, 왼쪽→오른쪽·오른쪽→왼쪽 복사(병합) 기능은 두지 않는다.

## 영향 사용자 및 시스템 (Affected users and systems)
- 화면: `src/pages/FileDiffModal.tsx`·`FileDiffModal.module.css`(구조 재구성), 표시 모델 `src/lib/file-diff-view.ts`(차이 묶음 인덱스·위치 막대용 데이터), 가상 목록 `src/lib/use-virtual-rows.ts`(행 인덱스로 스크롤)
- 공용 컴포넌트: 넓은 화면이 필요하면 `src/components/ZBCModal.tsx`·`ZBCModal.css`에 새 크기 추가(다른 모달 영향 확인)
- shared: `src/shared/text-diff.ts`는 그대로 쓰는 것이 기본. 줄 안 문자 단위 강조를 넣으면 shared 순수 함수 추가
- 테스트·문서: 단위(차이 묶음·이동 계산), E2E `tests/e2e/compare-diff.spec.ts`(머리글·문구 단언 갱신, 이동·선택 확인), `docs/CHANGELOG.md`

## 제약 (Constraints)
- 읽기 전용 유지(D-02): 파일 쓰기·전송·병합 동작을 만들지 않는다. main·IPC(`compare:fileDiff`)·`command-builder.ts`·`spawnTransfer`·계획 토큰은 바꾸지 않는 것이 전제다(AGENTS.md 1.2).
- AGENTS.md 1.5: renderer에서 Node API를 쓰지 않는다. 4.4·4.5: 공용 컴포넌트를 바꾸면 `ZBC` 규칙, 페이지 CSS는 `@layer pages`.
- 2MB 상한·바이너리·인코딩 안내(INT-009 동작)는 유지한다. 큰 파일에서도 가상 목록으로 렌더 성능을 지킨다(행 높이 22px 기준 일치).
- 새 외부 의존성 없이 구현하는 것이 기본(들이면 `THIRD_PARTY_NOTICES.md`).
- 완료 기준: `pnpm run check`·`format:check`·`test:e2e`(콘솔 오류 0)·`build:win`, CHANGELOG 한 줄.
