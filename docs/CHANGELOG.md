# Changelog

## [Unreleased]

- 2026-11-03: 제외 패턴을 `--filter-from` 파일로 전달 — 패턴이 하나라도 있으면 비교·미리보기·사전 확인·실제 실행·자동/OS 예약 실행이 모두 실행마다 만든 필터 파일 하나를 쓴다. `#`·`;`·`!`·앞 공백 패턴도 저장한 그대로 적용되고, 끝 공백이 있는 패턴은 `[ ]`로 바꿔 써서 rclone이 공백을 지워 다른 규칙이 되던 문제를 없앤다. 인자 전용 패턴 길이 예산(16,000자)이 사라져 그 이유로 저장이 막히지 않는다.
- 2026-11-03: 앱에서 rclone remote 추가·수정·삭제·재인증 추가 — 설정 화면에서 rclone이 지원하는 모든 종류를 고르고, providers 정의로 만든 입력 폼(고급 접기·비밀 가림)에 값을 넣어 remote를 만든다. OAuth 종류(Google Drive·OneDrive 등)는 브라우저 로그인으로 이어지고 남은 시간·취소·인증 주소·rclone 질문 폼을 보여 주며, 10분이 지나거나 취소하면 이번에 만든 반쪽 remote를 지운다. 기존 remote는 비밀 아닌 값만 채운 수정 화면에서 바꾸고, 삭제 전에 참조 작업·자동 실행·북마크 수를 보여 주며 예약 켜진 작업은 자동 실행을 끄고 Windows 예약을 지운 뒤 삭제한다. 비밀 값은 짧게 띄운 rcd의 HTTP 본문으로만 넘기고 앱 로그·이력·IPC 응답에 남기지 않는다. rclone 설정에 없는 remote를 쓰는 작업은 비교·실행 전에 멈추고 작업 목록에 “remote 없음”을 표시한다.
- 2026-10-28: 앱 골격 추가 — 창을 열면 앱 정보·저장된 작업 목록·데이터 위치를 보여 주고, 작업·설정을 `%APPDATA%\rcloneGUI`에 저장한다(손상 시 백업으로 복구). 비교·실행 화면은 아직 없다.
- 2026-10-28: rclone 자동 감지 추가 — 시작 화면에서 rclone 버전·경로·설정 파일·remote 목록을 보여 주고, rclone이 없거나 1.65.0 미만이면 설치 안내·직접 지정 배너를 띄운다. 로컬·UNC·remote 경로를 열 수 있는지 미리 확인하고, WSL 배포판의 리눅스 경로를 `\\wsl.localhost\...` 경로로 바꿔 준다.
- 2026-10-28: 작업 만들기·고치기·복제·삭제 화면 추가 — 왼쪽 목록에서 작업을 고르고, 원본·대상 경로(폴더 선택·WSL 도우미·remote 고르기·접근 확인), 제외 규칙, 작업별 rclone.conf, 고급·위험 옵션, 자동 실행 설정을 저장한다. 잘못된 경로·중첩 경로는 저장 전에 막고, 저장하지 않은 변경이 있으면 다른 작업으로 옮기기 전에 확인한다. 설정 화면에서 새 작업 기본값·안전 기준·로그 보관·테마를 바꾼다. 한 글자 이름 remote(`x:`)는 Windows에서 드라이브로 해석되므로 고를 수 없게 하고 경고한다. 비교·실행은 아직 없다.
- 2026-10-28: 폴더 비교 화면 추가 — 작업 화면의 ‘비교’를 누르면 원본·대상 목록을 읽기만 하고(파일은 바꾸지 않음) ‘대상에 12개 복사, 3개 덮어씀, 2개 삭제(동기화)/대상에만 있음(복사), 동일 N개’ 요약과 바이트, 파일별 좌우 크기·수정시간 표를 보여 준다. 상태 필터·경로 검색·동일 숨기기·정렬을 쓸 수 있고, 행이 많으면 보이는 부분만 그려 스크롤이 느려지지 않게 한다. 비교 중에는 취소할 수 있고, 취소·실패하거나 작업·설정을 바꾸면 이전 결과를 버린다. 대상 폴더가 없으면 모두 새로 복사할 파일로 보고 알려 준다. 실행(복사·동기화)은 아직 없다.
- 2026-10-28: 실행 화면 추가 — ‘미리보기’를 누르면 파일을 바꾸지 않고 rclone이 할 일(대상에 N개 복사, M개 수정시간만 맞춤, K개 삭제)과 샘플 경로를 보여 주고 비교 결과와 같은지 알려 준다. 비교한 뒤 ‘복사 실행’을 누르면 ‘대상에 3개 복사, 1개 덮어씀’ 확인 창을 거쳐 복사하고, 진행률·속도·남은 시간·최근 로그를 보여 준다. 실행 중에는 취소할 수 있고(이미 복사된 파일은 대상에 남음), 실행마다 이력과 `logs/run-*.log` 로그 파일을 남긴다. 실행 중 앱을 닫으면 rclone을 멈춘 뒤 종료하고, 비정상 종료로 남은 rclone은 다음 시작 때 정리한다. 동기화(삭제 포함) 실제 실행은 아직 없다(미리보기만 가능).
- 2026-10-29: 동기화(삭제 포함) 실제 실행 추가 — 비교한 뒤 ‘동기화 실행’을 누르면 삭제가 있을 때 삭제 확인 창(작업·원본·대상, ‘대상 파일 N개 중 M개 삭제’·바이트·비율, 삭제할 파일 최대 20개, 빈 폴더 정리 안내)에서 확인을 체크해야 ‘M개 삭제 포함 실행’을 누를 수 있고, 기준(50개 또는 대상의 10%)을 넘는 대량 삭제는 한 번 더 체크해야 한다. 실행 직전 같은 실행 안에서 미리보기로 다시 확인해 비교 뒤 원본·대상이 바뀌었으면 실행하지 않고(대상은 그대로) 다른 점과 ‘다시 비교’를 보여 준다. 실제 동기화는 계획한 삭제 수를 넘겨 지우지 않으며(넘으면 중단·실패), 원본이 비었거나 파일·폴더 이름이 겹치거나 ‘오류가 나도 계속’이 켜진 동기화는 실행하지 않는다. 작업 설정에서 사전 확인을 끄면 경고한다.
- 2026-10-29: 자동 실행·이력·트레이 추가 — 작업에 자동 실행을 켜 두면 앱이 켜져 있는 동안(트레이 포함) 주기마다 비교하고 바꿀 파일이 있을 때만 실행한다. 삭제가 필요하면 ‘자동 실행 때 삭제 허용’·‘자동 실행 최대 삭제 수’(기본 50, 0이면 금지) 이하·대량 삭제 아님·사전 확인 켜짐을 모두 만족할 때만 실행하고, 하나라도 어기면 아무것도 바꾸지 않고 알린다. 결과(완료·차단·실패·취소)는 창이 보이면 토스트, 숨겨져 있으면 Windows 알림으로 알린다. 상단 막대·트레이 메뉴에서 자동 실행을 일시정지하고 다음 자동 실행 시각을 본다. 작업 화면 ‘이력’ 탭에서 실행 목록(수동·자동·미리보기, 결과·걸린 시간·복사/삭제 수)과 상세(통계·오류·로그 끝부분)를 보고, 설정에서 이력을 비운다(로그 파일 삭제는 선택). 30일 지난 실행 로그는 시작할 때와 하루에 한 번 지운다. 창을 닫으면 트레이로 숨기고(설정에서 끄면 종료), 실행 중에 끝내려 하면 취소하고 끝낼지 묻는다. 설치본에서는 Windows 로그인 시 트레이로 시작할 수 있다.
- 2026-10-29: 사전 확인 불일치 안내의 ‘다시 비교’를 고침 — 안내가 떠 있는 동안 다른 작업을 골라 두었어도, 실행이 막혔던 작업을 다시 선택하고 비교 탭으로 옮긴 뒤 그 작업을 비교한다. 지금 보고 있는 작업(또는 설정 화면)에 저장하지 않은 변경이 있으면 먼저 변경 버리기 확인을 거친다.
- 2026-10-29: 취소로 남은 임시 파일 표시 추가 — 큰 파일을 복사하다 취소·실패하면 대상에 남는 rclone 임시 파일(`이름.8자리16진수.partial`)을 비교 목록과 동기화 삭제 확인 창에서 ‘취소로 남은 임시 파일’로 표시한다(파일은 그대로 둠). 실제 복사·동기화가 전송 도중 취소·실패로 끝나면 ‘대상에 임시 파일(.partial)이 남을 수 있다’고 토스트·실행 결과·이력 상세·자동 실행 알림으로 알린다.
- 2026-10-29: Windows 설치 파일과 사용 문서 추가 — NSIS x64 사용자 단위 설치본(`dist\rcloneGUI-Setup-0.1.0.exe`)에 앱 아이콘·바탕 화면/시작 메뉴 바로가기·언어 팩(ko·en-US)을 넣고, 제거해도 `%APPDATA%\rcloneGUI`의 작업·설정·이력은 보존한다. `pnpm run build:win`(= `dist`)으로 빌드하고 `pnpm run smoke:installer`로 임시 폴더 설치·실행·제거를 확인한다. - 2026-10-29: 작업·설정·이력을 `%APPDATA%\rcloneGUI\rclonegui-store.sqlite` 한 파일에 저장 — 처음 시작할 때 기존 `settings.json`·`jobs.json`·`history.json`을 옮기고 원본은 `*.json.migrated`(백업은 `*.json.bak.migrated`)로 남긴다. 시작할 때마다 저장소 손상을 검사해 손상되면 최근 백업으로 복구하고, 하루 한 번과 저장 구조를 바꾸기 전에 `db-backups\`에 백업한다.
- 2026-10-29: 공용 제외 패턴 추가 — 작업 편집기의 ‘공용 제외 패턴’에서 여러 작업이 함께 쓸 패턴을 추가·선택하고(같은 패턴은 하나만 저장), 바꾸거나 지우면 그 패턴을 쓰는 작업 목록(동기화·자동 실행 작업 강조)을 확인한 뒤 모든 작업에 바로 적용하고 그 작업들의 비교 결과를 버린다(다시 비교해야 실행). 기존 제외 규칙은 ‘이 작업에만 쓰는 제외 패턴’으로 그대로 남고, `#`·`;`로 시작하는 패턴은 공용으로 둘 수 없다. 제외 패턴이 많으면(64개 초과) rclone에 임시 파일(`--exclude-from`)로 넘겨 명령 길이 한도를 피하고, 비교 뒤 제외 패턴이 바뀌면 실행을 막는다. 새로 저장하는 경로는 4096자까지, 제외 패턴은 공용과 작업 전용을 합쳐 500개까지다. 저장소 구조가 v2로 바뀌며 바꾸기 전 `db-backups\`에 백업한다.
- 2026-11-01: remote 북마크·폴더 탐색 추가 — 설정 화면에서 rclone.conf의 remote와 그 안의 기준 경로를 별칭으로 저장하고 연결 테스트(`lsjson --max-depth 1 --dirs-only`)로 폴더 존재를 확인한다. 작업 편집기의 경로 입력에서 북마크를 고르거나 폴더를 한 단계씩 내려가며 골라 원본·대상 경로에 넣는다. 탐색은 앱에서 한 번에 하나만 실행하고, 같은 remote를 비교·실행 중이면 막되 다른 remote는 허용한다. 탐색은 그 작업의 rclone.conf로 하고, 북마크는 기본 설정 파일에서 remote 이름만 확인한다.
- 2026-11-02: 동기화 범위와 작업 목록 확장 — 작업 편집기에서 ‘파일만’(기본, 지금과 같음)과 ‘전체(빈 폴더 포함)’를 고른다. 전체 범위는 원본의 빈 폴더를 대상에 만들고, 동기화하면 대상에만 있는 폴더도 지운다. 비교 화면에 ‘빈 폴더 N개 생성, 폴더 M개 삭제’를, 삭제 확인 창에 지울 폴더 수·샘플을 보여 주고, 실행 직전 사전 확인에서 폴더 삭제 수까지 맞춰 본다(자동 실행의 삭제 허용·최대 삭제 수에도 폴더를 더해 센다). 비교 뒤 범위를 바꾸면 다시 비교해야 실행한다. 왼쪽 작업 목록에 원본 → 대상, 자동 실행 주기·다음 실행, 최근 실행 시각·상태 문구를 보여 주고(설정 ‘화면’에서 상태 문구를 숨길 수 있음), ‘실행’ 버튼으로 그 작업을 비교한 뒤 확인 창(삭제가 있는 동기화는 삭제 확인 창)을 거쳐 실행한다.
- 2026-11-02: 자동 실행 예약과 작업 화면 단계 정리 — 자동 실행을 ‘일정 간격마다’(분·시간), ‘매일 정한 시각’, ‘요일과 시각 지정’(예: 매주 월·수 09:00) 중에서 고르고, 저장하기 전에 다음 실행 시각을 보여 준다(이 PC 시각 기준, 서머타임에도 하루 한 번). 작업 목록·배지에 ‘1시간마다’, ‘매일 09:00’처럼 보인다. 자동 실행이 예약된 채 트레이 메뉴의 ‘종료’를 누르면 다음 예약을 알리고 종료할지 묻는다(창 X로 끝낼 때는 묻지 않음). ‘로그인 시 시작’이 꺼진 채 자동 실행을 켜면 한 번 안내한다. 작업 화면 탭을 ‘비교·미리보기 → 실행 → 결과·이력’ 순서로 바꾸고 미리보기 결과는 첫 탭에 보이며, 탭마다 있던 취소 버튼 대신 진행 중일 때만 나타나는 중지 버튼 하나(‘비교 중지’, ‘복사 중지’ 등)를 둔다. 진행 중인 작업을 멈춘 결과는 ‘중지됨’, remote는 ‘리모트’, 바꿀 것이 없으면 ‘바꿀 것 없음’으로 표기를 맞추고, 동기화에서 ‘오류가 나도 계속’을 켰을 때의 안내를 한 문장으로 통일했다(백업 폴더는 아직 지정할 수 없음).
