# Changelog

## [Unreleased]

- 2026-10-28: 앱 골격 추가 — 창을 열면 앱 정보·저장된 작업 목록·데이터 위치를 보여 주고, 작업·설정을 `%APPDATA%\rcloneGUI`에 저장한다(손상 시 백업으로 복구). 비교·실행 화면은 아직 없다.
- 2026-10-28: rclone 자동 감지 추가 — 시작 화면에서 rclone 버전·경로·설정 파일·remote 목록을 보여 주고, rclone이 없거나 1.65.0 미만이면 설치 안내·직접 지정 배너를 띄운다. 로컬·UNC·remote 경로를 열 수 있는지 미리 확인하고, WSL 배포판의 리눅스 경로를 `\\wsl.localhost\...` 경로로 바꿔 준다.
- 2026-10-28: 작업 만들기·고치기·복제·삭제 화면 추가 — 왼쪽 목록에서 작업을 고르고, 원본·대상 경로(폴더 선택·WSL 도우미·remote 고르기·접근 확인), 제외 규칙, 작업별 rclone.conf, 고급·위험 옵션, 자동 실행 설정을 저장한다. 잘못된 경로·중첩 경로는 저장 전에 막고, 저장하지 않은 변경이 있으면 다른 작업으로 옮기기 전에 확인한다. 설정 화면에서 새 작업 기본값·안전 기준·로그 보관·테마를 바꾼다. 한 글자 이름 remote(`x:`)는 Windows에서 드라이브로 해석되므로 고를 수 없게 하고 경고한다. 비교·실행은 아직 없다.
- 2026-10-28: 폴더 비교 화면 추가 — 작업 화면의 ‘비교’를 누르면 원본·대상 목록을 읽기만 하고(파일은 바꾸지 않음) ‘대상에 12개 복사, 3개 덮어씀, 2개 삭제(동기화)/대상에만 있음(복사), 동일 N개’ 요약과 바이트, 파일별 좌우 크기·수정시간 표를 보여 준다. 상태 필터·경로 검색·동일 숨기기·정렬을 쓸 수 있고, 행이 많으면 보이는 부분만 그려 스크롤이 느려지지 않게 한다. 비교 중에는 취소할 수 있고, 취소·실패하거나 작업·설정을 바꾸면 이전 결과를 버린다. 대상 폴더가 없으면 모두 새로 복사할 파일로 보고 알려 준다. 실행(복사·동기화)은 아직 없다.
- 2026-10-28: 실행 화면 추가 — ‘미리보기’를 누르면 파일을 바꾸지 않고 rclone이 할 일(대상에 N개 복사, M개 수정시간만 맞춤, K개 삭제)과 샘플 경로를 보여 주고 비교 결과와 같은지 알려 준다. 비교한 뒤 ‘복사 실행’을 누르면 ‘대상에 3개 복사, 1개 덮어씀’ 확인 창을 거쳐 복사하고, 진행률·속도·남은 시간·최근 로그를 보여 준다. 실행 중에는 취소할 수 있고(이미 복사된 파일은 대상에 남음), 실행마다 이력과 `logs/run-*.log` 로그 파일을 남긴다. 실행 중 앱을 닫으면 rclone을 멈춘 뒤 종료하고, 비정상 종료로 남은 rclone은 다음 시작 때 정리한다. 동기화(삭제 포함) 실제 실행은 아직 없다(미리보기만 가능).
- 2026-10-29: 동기화(삭제 포함) 실제 실행 추가 — 비교한 뒤 ‘동기화 실행’을 누르면 삭제가 있을 때 삭제 확인 창(작업·원본·대상, ‘대상 파일 N개 중 M개 삭제’·바이트·비율, 삭제할 파일 최대 20개, 빈 폴더 정리 안내)에서 확인을 체크해야 ‘M개 삭제 포함 실행’을 누를 수 있고, 기준(50개 또는 대상의 10%)을 넘는 대량 삭제는 한 번 더 체크해야 한다. 실행 직전 같은 실행 안에서 미리보기로 다시 확인해 비교 뒤 원본·대상이 바뀌었으면 실행하지 않고(대상은 그대로) 다른 점과 ‘다시 비교’를 보여 준다. 실제 동기화는 계획한 삭제 수를 넘겨 지우지 않으며(넘으면 중단·실패), 원본이 비었거나 파일·폴더 이름이 겹치거나 ‘오류가 나도 계속’이 켜진 동기화는 실행하지 않는다. 작업 설정에서 사전 확인을 끄면 경고한다.
- 2026-10-29: 사전 확인 불일치 안내의 ‘다시 비교’를 고침 — 안내가 떠 있는 동안 다른 작업을 골라 두었어도, 실행이 막혔던 작업을 다시 선택하고 비교 탭으로 옮긴 뒤 그 작업을 비교한다. 지금 보고 있는 작업(또는 설정 화면)에 저장하지 않은 변경이 있으면 먼저 변경 버리기 확인을 거친다.
